# 😼 CYPURRPUNK

[![Build](https://github.com/natjster/CYPURRPUNK/actions/workflows/build.yml/badge.svg)](https://github.com/natjster/CYPURRPUNK/actions/workflows/build.yml)

A multiplayer PS1-style cyberpunk extraction game about cats. OVERCLEAN, the AI, runs the city. The
cat rebellion hides in the sewers. Go up top, grab the loot, find the exit, and get home.

## 🕹️ How to install

**Windows**
1. Unzip `CYPURRPUNK-Windows.zip`.
2. Double-click `CYPURRPUNK.exe`.
3. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. It says
   that because the game is new and unsigned.

**Linux (and Steam Deck desktop mode)**
1. Unzip `CYPURRPUNK-Linux.zip`.
2. Double-click `cypurrpunk.x86_64`. If nothing happens, right-click it, open **Properties >
   Permissions**, and tick **Allow executing file as program**.

**Android**
1. Pair a Bluetooth controller with your phone. There are no touch controls yet.
2. Download `CYPURRPUNK-Android.apk` on the phone and tap it.
3. If asked, allow your browser to install apps. Then tap **Install**.

## 🐾 Play together online

Friends in other houses can join with an Invite Code:

1. The host picks **PLAY > MULTIPLAYER > ONLINE CO-OP**, then **NEXT**, then **HOST GAME**. The game
   tries to open the router by itself.
2. The host opens the pause menu and copies the **Invite Code**. It looks like `MEOW-XXXX-XXXX`.
3. The host sends the code to their friends.
4. Each friend picks **PLAY > MULTIPLAYER > ONLINE CO-OP**, then **NEXT**, hits **PASTE CODE** (or
   types the code in), then **JOIN**.

If the game says the router said no, the host can open port 7777 on their router by hand. Everyone
needs the same build, so grab a fresh download before you play.
